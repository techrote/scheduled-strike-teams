## How to interpret recommended schedules

- **N** = suggested *productive hourly-worker count when concentrating on this one repository*, assuming exclusive, separately-owned workstreams. The global concurrent cap remains **10 active hourly schedules total** across all repositories.
- **0** = no **additional hourly worker** is recommended *now*: the next value is mostly owner acceptance, manual GPT-6 Pro reconciliation, permissions or physical testing. **0 does not mean the repository is worthless or complete.**
- **Gate first** = only activate when the named owner/external requirement is satisfied. All numbers are contingent and may be revised after a single live-source preflight.
- *Ready for human review* means a **scope-specific**, exact-SHA evidenced handoff; does not establish entire product/release acceptance if other milestones remain.
- The recommended worker counts are **not** an accounting of current/previous scheduled assignments. Check the live automation list for actual occupancy before creation.
